# Best visitors — asset license and provenance

The character meshes, UV maps, skin textures, garment textures, hair, eyebrows,
eyes, shape targets, skeleton and skin weights are derived from the official
**MakeHuman Community core assets**, released under **CC0 1.0 Universal**.
The original authors credited in those files are Data Collection AB,
Joel Palmius and Jonas Hauquier / the MakeHuman team.

Primary license records:

- [MakeHuman asset license](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md)
- [Complete upstream CC0 dedication](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.ASSETS.md)
- [System asset pack: per-asset authors and CC0 declarations](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)
- [CC0 1.0 Universal legal text](https://creativecommons.org/publicdomain/zero/1.0/legalcode)

XpaceOS adaptations include fitted garments, reduced deformation hierarchy,
materials, browser export and the authored Idle/Walk animation clips.
Those graphical adaptations and exported `.blend` / `.glb` assets are also
provided under CC0 1.0 Universal. This file describes asset rights only;
it does not change the license of unrelated XpaceOS application source code.

The graphical assets were processed as data by an independent Blender builder.
No MakeHuman application source code or add-on is included or executed by that
builder. MakeHuman's separate application code license does not describe these
CC0 assets.

Build instructions, exact source URLs, byte sizes and SHA256 checksums are in
[`../../../tools/people-blender/`](../../../tools/people-blender/).
The complete 267 MiB system archive is downloaded to the developer's cache;
it is not redistributed as part of this repository.

These visitors are a first iteration with anatomically human meshes and
skeletal animation. They are not photorealistic AAA characters, scans of real
people, or assets taken from GTA. Heights in the simulation are artistic and
have not been calibrated against real individuals.
