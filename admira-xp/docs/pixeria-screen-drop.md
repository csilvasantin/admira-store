# Pixeria, creación y arrastre a pantallas / Pixeria, creation and screen drops

## Español

Opciones → Hilo Musical, Imagen o Vídeo conecta con la biblioteca publicada de Pixeria: elige un #hashtag y un contenido del desplegable. Importar prepara el previo sin emitir ni generar una copia. La generación está en Experto → Crear contenidos: imagen y vídeo conservan sus campos y trabajos recuperables; música abre el creador de Pixeria y sus entregas quedan preparadas en Stock. Pasa sobre el previo de imagen o vídeo: el cursor se convierte en una mano. Mantén pulsado y arrastra; una miniatura del contenido sigue al ratón hasta soltarla en la pantalla o playlist elegida, sin botón adicional. Los controles de vídeo siguen disponibles en la franja inferior. Escape o soltar fuera cancela el arrastre. También puedes arrastrar una fila de la playlist. Disponible en Good, Better, Best y Matrix. Soltar en una pantalla muestra sólo allí el contenido, sin audio y de forma temporal; Recargar pantalla recupera su programación guardada. En Matrix funciona con Layout cerrado y conserva las otras pantallas, TPV, asignaciones, IDs y música; las pantallas apagadas permanecen apagadas. Soltar en Playlist actual añade sin cambiar la emisión; Lanzar sigue incorporando y reproduciendo en el grupo elegido. El filtro de hashtags es exacto; también admite títulos y números de Stock. El catálogo mantiene los IDs y URLs estables y usa el archivo original disponible. La calidad de la vista no cambia la resolución del archivo. Son reproductores virtuales de este Xpacio, sin publicación física.

## English

Options → Background music, Image or Video connects to the published Pixeria library: choose a #hashtag and an item from the dropdown. Importing stages a preview without playback or generating a copy. Generation is in Expert → Create media: image and video retain their fields and recoverable jobs; music opens the Pixeria creator and its deliveries become staged Stock media. Hover over an image or video preview: the cursor becomes a hand. Hold and drag; a content thumbnail follows the pointer until you drop it onto the chosen screen or playlist, without an extra button. Video controls remain available along the bottom. Escape or dropping outside cancels the drag. You can also drag a playlist row. Available in Good, Better, Best and Matrix. Dropping on a screen displays the content only there, muted and temporarily; Reload screen restores its saved schedule. Matrix works with Layout closed and preserves other screens, POS, assignments, IDs and music; powered-off screens remain off. Dropping onto Current playlist adds without changing playback; Launch still adds and plays in the chosen group. Hashtag filters match exactly; titles and Stock numbers also work. The catalog retains stable IDs and URLs and uses the available original file. View quality does not change file resolution. These are virtual players in this Xpace, without physical publishing.

## Contratos / Contracts

- Library: https://stock.admira.store/stock/index.json, the same index as Pixeria Stock. Public read with credentials omitted. Types: music, image, video; announcements/audio, hidden records and invalid source URLs are excluded. No generated copy, payment or automatic player action on selection. Native hashtag input with suggestions and content dropdown.
- Stable selected asset: https://api.admira.store/stock/asset/<id>; the catalog num field retains its identity. Ready state uses existing xpaceos.options-media-ready.v1 session storage, without automatically restoring screen playback.
- Creation IDs remain imagePrompt, videoPrompt and videoPreview; controllers initialize after the moved forms exist. Expert category creation is appended to the retained categories. Expert, /marca, CLI history, voices, and saved device layouts remain available and start closed. Music creation uses https://www.pixeria.com/musica.html (English: /en/musica.html), its existing authorization and delivery pipeline. No new paid music generator.
- Pointer drop contract: screenAt/client coordinates, screenHighlight, previewScreen(id, track), restoreScreen(id). Track kind image/video; music belongs to the background music playlist. Escape, pointer cancel and an outside drop cancel. Imported and generated previews and current playlist rows share the same gesture. No overlay captures an ordinary screen interaction outside dragging.
- Good uses its native canvas quads; Better and Best 3D use ray intersection with real screen surfaces. Best photographic surfaces follow their atlas/sprite aperture and existing inventory transforms. Stock media is drawn from the original URL, with aspect ratio preserved.
- Starbucks IDs: physical screen N maps to starbucks-wall-0(7-N); screen 4 = starbucks-wall-03; POS = starbucks-tpv-01. Good/Better/Best retain these IDs. Matrix uses the existing runtime.preview([id],track) and deviceEditor.reload([id]); it does not write shared assignments/playlists, power on disabled devices or change background music. Existing /layout multiple-screen preview remains separate.
- Original Xtanco surfaces: ds1, ds2, escaparate, metahuman; inventory LED surfaces use inventory:<instance-id>. Direct drops are local and temporal; existing players/pins remain available underneath and return on Reload screen. A page reload does not reapply temporary screen drops.
- Shared agent operations stay unchanged: pixeria_search, playlist_list/add/reorder/play, matrix_preview and matrix_device_layout. For remote Matrix preview use matrix_preview with the agent own credentials and current Matrix expected_revision. A saved command is not a physical playback acknowledgement.
- Browser bridge: XpaceMediaOptions.stage/get; XpaceOptionsPlayback, XpaceSceneScreens, XpaceMatrixOptions; XpaceScreenMedia preview/draw/restore. Existing Stock/provider endpoints and credentials remain unchanged.

Verification: preview frame/image follows pointer, isolated device drop, cancellation without playback, playlist add without autoplay, library filtering, URL/type isolation, muted video, failed replacement retention, exact Matrix target/off guard, native Good/Better/Best/Matrix gestures, ES/EN and generator recovery. Real MCP help includes pixeria-screen-drop.
