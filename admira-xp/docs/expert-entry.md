# Experto replegado / Collapsed Expert

Al entrar en el gemelo, Opciones, Avanzados y Experto empiezan replegados: solo se ve la barra superior. La carga de Better, Best o Matrix no abre Experto. El botón ⌘ permite abrirlo y cerrarlo.

On twin entry, Options, Advanced and Expert start collapsed: only the top bar is visible. Loading Better, Best or Matrix does not open Expert. The ⌘ button opens and closes it.

Source: scripts/xtanco-premium-ui.mjs. No auto-opening calls during tier selection or startup.
