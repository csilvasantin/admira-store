- Inventory entry: https://www.xpaceos.com/inventario/cafebreria/
- Deep link: /xpacios/cafebreria/?inventory=1&asset=silla-1 (add &edit=1 for editing; &lang=en for English).
- Source roster: inventario/cafebreria/scene.inventory.json. All 82 GLB scene roots have distinct records; the runtime bookcase adds one, giving 83 models. Fifteen formerly unlisted source roots now have glb-node:<original index> identities, including six source books and eight bookcase parts plus Cube. Original 81 identities and library native:cafebreriaLibrary / catalogue 51 are unchanged. The original GLB hash is unchanged.
- Scene ITIL IDs: cafebreria:<original id>; these are visual scene records, not remote Yokup asset IDs. Original manufacturer/model/warranty remain blank until edited.
- Thirteen existing sinGeometria records remain pending: router, switch, UPS, camera, alarm, separate grinder, payment terminal, ticket printer, dishwasher, oven, undercounter fridge, HVAC and music amplifier. Their records are editable; no invented 3D models or dimensions are supplied.
- Shared engine: life-renderer.mjs → life-scene.mjs → life-exterior.mjs. Imported scene integration: imported-space.mjs. Editor: unchanged common mountDistribuit/controller/validator/object planner, extended to accept a stage as the root. Solid footprints use the imported floor elevation; architecture and elevated fixture geometry do not create phantom floor obstacles.
- All nonstructural model instances support ground-plane movement, rotation, scaling, locks, removal and guarded undo. Wall/ceiling height is retained; architectural objects stay fixed. Per-item visibility is reversible.
- Local persistence: xpaceos:imported-space:v1:cafebreria, one atomic browser storage value for layout, object ledger and editable records. Writes succeed before state changes. Persistence failure retains the prior pose. Origins/domains have separate browser storage. No remote CMDB write, physical broadcast or new MCP tool.
- PixerIA import decodes through the shared bounded loader, checks placement, saves, and then mounts its own imported object. Broken loads do not save substitutes. Reloaded imports use the same source URL. Undo/remove hides imported geometry; restoring the factory layout removes added instances.
- /marca (/brand), Expert command history and /avatarDigital registration remain owned by the common shell. Capsule selection is suspended during editing so a drag cannot open or play a book. Closing the editor restores book interactions.
- Web help, tutorial, CLI help, manifest/functional contracts and actual MCP help describe this usage in ES/EN.
