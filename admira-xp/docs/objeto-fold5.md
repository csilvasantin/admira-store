# Objeto · Samsung Galaxy Z Fold5

## Español

Abre **Xpaces → Objeto → Samsung Galaxy Z Fold5** o visita [el gemelo](https://www.admira.store/objeto/galaxy-z-fold5/). En el gestor de Admira TV escribe un número o una etiqueta de Stock, revisa el previo Sony y pulsa **Importar**. Usa **Playlist del gemelo** y las flechas para cambiar de pieza. **Plegar** muestra la cubierta con la variante vertical y **Abrir** muestra la pantalla interior con la horizontal. Cuando una pieza tiene una sola variante, el gemelo la encuadra en ambas pantallas.

El objeto tiene el ID `galaxy-z-fold5`. La playlist se guarda en ese navegador con la clave `admira-fold5-playlist-v1`. El importador y la señal vienen de `https://admira.tv`. El gemelo reproduce imágenes y vídeos de Stock. El control del Samsung físico por USB queda pendiente.

## English

Open **Xpaces → Object → Samsung Galaxy Z Fold5** or visit [the twin](https://www.admira.store/objeto/galaxy-z-fold5/). Enter a Stock item number or tag in the Admira TV panel, check the Sony preview and select **Importar**. Use the twin playlist and arrow buttons to change items. Fold the twin to see the portrait version on its cover screen and open it to see the landscape version inside. A single available version is fitted to both screens.

The object ID is `galaxy-z-fold5`. The playlist is stored in that browser under `admira-fold5-playlist-v1`. The importer and the feed come from `https://admira.tv`. The twin plays Stock images and videos. USB control of the physical Samsung is pending.
