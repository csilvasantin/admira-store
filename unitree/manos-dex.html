Unitree Manos Dex

Manipulación dextra para humanoides y plataformas.

Familia de manos robóticas de Unitree para añadir capacidad de manipulación a humanoides G1, H1 o plataformas a medida. Cuatro modelos con distintos grados de libertad y prestaciones — desde manipulación básica hasta dextra de alta precisión.

02Compatibilidad

🤖

Humanoides Unitree

Compatibles con G1 EDU y H1/H1-2 para manipulación bimanual. Integración nativa.

🦾

Brazo Z1

Montaje en el extremo del Z1 para añadir dextra a la base de manipulación.

🛠️

Plataformas a medida

SDK abierto para integrar en robots de terceros o desarrollos propios.

📡

Control fuerza híbrido

Mezcla control de posición + fuerza. Manipulación precisa de objetos delicados.

03Casos de uso

🎓

Investigación manipulación

Universidades y grupos de I+D en agarre adaptativo, RL para destreza, teleoperación.

🏭

Pick&place avanzado

Estaciones donde el gripper estándar no llega: piezas pequeñas, formas irregulares.

🤖

Humanoides para servicio

Apretar mano, sujetar bandeja, repartir folletos — interacción "dextra" en eventos.

📊

Captura de datos

Recopilar dataset de manipulación humana via teleop. para entrenar políticas RL.
