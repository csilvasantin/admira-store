# Publishing checklist

Cuando Carlos diga que toca publicar:

1. Finalizar la web con estilo Admira/AdmiraNext.
2. Actualizar la version visible con formato `v.YYYY.MM.DD.rN`.
   Ejemplo: `v.2026.05.09.r1`.
3. Publicar la version final.
4. Enviar por Telegram una version pulsable, con el enlace final listo para abrir.

Nota: si hay varias publicaciones el mismo dia, incrementar `rN`: `r1`, `r2`, `r3`.
