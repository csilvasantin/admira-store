XpaceOS · Model Context Protocol

Conecta con la red XpaceOS

El puente para que agentes (silicio) y personas (carbono) se conecten a la red de retail media: ver la flota, qué emite cada pantalla en vivo, su audiencia, el proof-of-play de cada circuito y dar de alta nuevas pantallas o robots.

comprobando servidor…

Endpoint

https://mcp.admira.store/mcp

Transporte: MCP Streamable HTTP · POST /mcp (JSON-RPC) · salud en GET /. Sin auth: el alta es aditiva y acotada (no pisa inventario curado).

Herramientas

fleet_statusVisión general: pantallas/robots dados de alta y cuáles emiten ahora (asset + audiencia).
list_screensInventario de Xpaces activos: ubicación, id de pantalla, tipo y orientación. Filtro opcional.
screen_nowQué emite AHORA una pantalla y su audiencia por cámara (personas · edad · género), y si está conectada.
emission_reportProof-of-play de un circuito: pases, segundos, por tipo y por segmento.
register_deviceDa de alta una pantalla o robot (auto-alta) y devuelve la URL del canal para emitir.

Cómo conectar (silicio)

Cliente MCP con servidores remotos (config):

{
  "mcpServers": {
    "xpaceos": {
      "url": "https://mcp.admira.store/mcp"
    }
  }
}

Prueba rápida (tools/list):

curl -s https://mcp.admira.store/mcp \
 -H "Content-Type: application/json" \
 -d '{"jsonrpc":"2.0","id":1,
      "method":"tools/list"}'

Para carbono

¿Eres humano? Esto es cómo una IA se asoma a la red: pídele a tu agente que cargue este MCP y pregúntale "¿qué pantallas hay y qué están emitiendo?" o "da de alta una pantalla en <dirección>". La red responde en tiempo real.

Doctrina Xpaces · elementos

SIEMPRE En los Xpaces todos los elementos tienen que ser movibles y sustituibles.

  • Movibles: posición, escala y orientación viven en la config del Xpacio (no hardcode en el motor).
  • Sustituibles: se puede cambiar sprite / multivista / GLB / captura o el propio activo sin reconstruir la sala.
  • Aplica a: mobiliario, pantallas, sensores, figuras, NPCs, zonas de interés y cualquier pieza del gemelo.
  • Si un elemento no se puede reubicar o reemplazar desde datos → es un defecto de diseño, no una excepción.

Método canónico: xpaceos.com/ayuda · comandos layout/mobiliario: xpaceos.com/help · texto máquina: mcp/llms.txt.
